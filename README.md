# HAP Server - Web

![](https://github.com/user-attachments/assets/ebbcc3b8-be5b-4e6c-9914-5fc485190167)

Unlock comprehensive frontend customization capabilities to create a unique visual experience and customized features.

[![nocoly](https://img.shields.io/badge/I%20%E2%9D%A4%20MY%20TEAM-blue)](https://www.nocoly.com) [![issues](https://img.shields.io/github/issues/nocoly/pd-openweb)](https://github.com/nocoly/pd-openweb/issues) [![star](https://img.shields.io/github/stars/nocoly/pd-openweb)](https://github.com/nocoly/pd-openweb/stargazers)

**Note:** The source code version must match the deployed HAP version. Otherwise, API incompatibility may occur. Once you choose to customize the source code, you will need to merge your customizations with the corresponding source code version whenever HAP Private Deployment is upgraded.

👉 [Quick Start](https://docs-pd.nocoly.com/en/hap/sd/web/start)
